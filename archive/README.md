# Archive

The record pushed to Google Drive for October 2026.

| File | What it is |
|---|---|
| `complete-item-level-record.csv` | Every mark, every class, every working day — 638 class-days, 9,570 item marks |
| `checklist-YYYY-MM-DD.csv` | One file per working day (22 files), the page-1 form as filled |
| `teachers.csv` | 29 incharges: composite, grade, pillar %, weakest item, remark |
| `daily-checklist.csv` | Daily roll-up: classes marked, points, average % |
| `attendance-register.csv` | Weekly assembly/class attendance per class |
| `improvement-register.csv` | Undertakings with owners, measures and due dates |
| `rubric.csv` | The 15 items, scoring options, pillar and remedial action |
| `school-report.html` | The monthly report, print-ready |
| `teacher-findings.html` | One finding per teacher below 70%, a page each |

Regenerate after changing any mark: open the console → **Reports**, or
**Data & Sync → Download backup**, then re-export.
